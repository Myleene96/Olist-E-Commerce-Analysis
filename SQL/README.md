# SQL Analysis

I used MySQL to analyze the Olist e-commerce dataset and explore sales, customers, payments, delivery performance, and reviews.

## Analysis Topics

- **Sales Performance:** Monthly revenue trends and top-performing product categories
- **Payment Analysis:** Payment methods, payment value, and installments
- **Customer Analysis:** Repeat purchase rate and revenue by state
- **Delivery Performance:** Average delivery time and late-delivery rates
- **Customer Reviews:** Review scores across product categories
